No-Purchase-Necessary Structure

How It Works

Gold Coins

  • Non-redeemable
  • Entertainment only
  • Earned through gameplay
  • No real-money value

Sweeps Coins

  • Redeemable for prizes
  • Free-entry method
  • Earned through gameplay/bonuses
  • Represents sweepstakes entries

Legal Compliance Requirements

Platforms using this structure must comply with:

  • ✓ Clear Disclosure: Explicitly state that sweepstakes are free-entry and no purchase is necessary
  • ✓ Official Rules: Provide comprehensive official rules accessible to all players
  • ✓ Odds Publication: Clearly display odds of winning prizes
  • ✓ Age Verification: Implement robust age verification (18+ or 21+ depending on state)
  • ✓ Geographic Restrictions: Block access from restricted states and enforce state-specific limitations
